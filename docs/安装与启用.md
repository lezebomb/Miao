# 安装与启用“妙妙”

## 自动安装（Windows）

在仓库根目录打开 PowerShell：

```powershell
.\install.ps1
```

脚本会把：

- `pet/miaomiao/pet.json`
- `pet/miaomiao/spritesheet.webp`

复制到：

```text
%USERPROFILE%\.codex\pets\miaomiao
```

完全退出并重新打开 Codex，然后在宠物选择器中选择“妙妙”。

## 手动安装

把整个 `pet/miaomiao` 文件夹复制为：

```text
%USERPROFILE%\.codex\pets\miaomiao
```

最终目录必须恰好包含：

```text
miaomiao/
  pet.json
  spritesheet.webp
```

不要把 `spritesheet.webp` 改名；`pet.json` 中的 `spritesheetPath` 与它对应。

## macOS / Linux

```bash
./install.sh
```

默认目标是 `${CODEX_HOME:-$HOME/.codex}/pets/miaomiao`。

## 未显示时

1. 确认 Codex 已完全退出，而不是只关闭窗口。
2. 确认 `pet.json` 和 `spritesheet.webp` 在同一目录。
3. 确认 `pet.json` 中存在 `"spriteVersionNumber": 2`。
4. 重新打开 Codex，再检查宠物选择器。

本项目不包含音频，安装后完全静音。
