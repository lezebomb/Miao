# 安装与启用“妙妙”

## 自动安装（Windows）

在仓库根目录打开 PowerShell：

```powershell
.\install.ps1
```

脚本会把：

- `pet/miaomiao/pet.json`
- `pet/miaomiao/spritesheet.webp`

复制到：

```text
%USERPROFILE%\.codex\pets\miaomiao
```

打开 Codex 的“设置 → 宠物”，点击右上角的刷新按钮，然后选择“妙妙”。

## 手动安装

把整个 `pet/miaomiao` 文件夹复制为：

```text
%USERPROFILE%\.codex\pets\miaomiao
```

最终目录必须恰好包含：

```text
miaomiao/
  pet.json
  spritesheet.webp
```

不要把 `spritesheet.webp` 改名；`pet.json` 中的 `spritesheetPath` 与它对应。

## macOS / Linux

```bash
./install.sh
```

默认目标是 `${CODEX_HOME:-$HOME/.codex}/pets/miaomiao`。

## 未显示时

1. 先在“设置 → 宠物”点击右上角刷新。自定义宠物列表不会持续自动扫描。
2. 确认 `pet.json` 和 `spritesheet.webp` 在同一目录。
3. 确认 `pet.json` 中存在 `"spriteVersionNumber": 2`。
4. 确认最终图集是 `1536×2288`。
5. 完全退出并重新打开 Codex，再检查宠物选择器。

### Windows + WSL 兼容启动

Codex 26.715 在 Windows 界面使用 WSL 后台时，可能把 Windows 的
`C:\Users\<用户>\.codex\pets` 错误交给 WSL 的 POSIX 文件接口。此时目录和文件
都正确，但自定义宠物仍会被静默忽略。

项目提供了不修改系统级环境变量的兼容启动器：

1. 从系统托盘完全退出 Codex，确保任务管理器中没有属于 Codex 的 `ChatGPT.exe`；
2. 双击仓库根目录的 `launch-codex-miaomiao.cmd`；
3. 启动后进入“设置 → 宠物”；
4. 点击右上角刷新，选择“妙妙”。

也可以在 PowerShell 中检查启动条件而不启动应用：

```powershell
.\launch-codex-miaomiao.ps1 -CheckOnly
```

启动器会自动定位 Microsoft Store 安装的 Codex 与妙妙目录，默认使用本项目
验证过的 `Ubuntu` 发行版，只为新启动的 Codex 进程设置 `WSL_DISTRO_NAME` 和
`CODEX_HOME`。关闭该进程后设置立即失效。若 WSL 发行版不是 Ubuntu，可运行：

```powershell
.\launch-codex-miaomiao.ps1 -WslDistro "你的发行版名称"
```

本项目不包含音频，安装后完全静音。
