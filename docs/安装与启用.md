# 安装与启用“妙妙”

## 推荐：一键同步并启动 Codex

1. 从系统托盘完全退出 Codex。
2. 双击仓库根目录的 `launch-codex-miaomiao.cmd`。
3. 启动器会自动同步当前仓库里的 `pet.json` 和 `spritesheet.webp`，并校验哈希。
4. 在 Codex 的“设置 → 宠物”中刷新并选择“妙妙”。

只同步并检查环境、不启动 Codex：

```powershell
.\launch-codex-miaomiao.ps1 -CheckOnly
```

跳过同步，仅检查已安装文件：

```powershell
.\launch-codex-miaomiao.ps1 -CheckOnly -SkipSync
```

## 传统安装

在仓库根目录运行：

```powershell
.\install.ps1
```

脚本会把以下文件复制到 `%USERPROFILE%\.codex\pets\miaomiao`：

- `pet/miaomiao/pet.json`
- `pet/miaomiao/spritesheet.webp`

最终安装目录必须包含：

```text
miaomiao/
  pet.json
  spritesheet.webp
```

图集必须是 `1536×2288`，且 `pet.json` 必须包含 `"spriteVersionNumber": 2`。

## 项目扩展桌宠

要使用随机抚摸、14 帧踩奶、14 帧洗脸和 16 帧打滚，请双击：

```text
launch-miaomiao-desktop.cmd
```

这是因为当前 Codex 客户端的 hover 和标准状态帧数是固定协议，不能由 `pet.json` 自定义随机动作池。

本项目不包含音频，两个启动方式都保持静音。
