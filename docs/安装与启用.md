# 启动与配置

## 统一启动

双击仓库根目录：

```text
launch-miaomiao-with-codex.cmd
```

脚本只处理原生 Windows Codex，不读取或设置任何 WSL 环境变量。若 Codex 尚未运行，脚本会从已安装的 `OpenAI.Codex` AppX 包定位 `ChatGPT.exe` 并启动；主窗口出现后，透明妙妙窗口会跟随它。

不需要运行 `install.ps1`，也不需要把妙妙复制到 `%USERPROFILE%\.codex\pets`。

## 单独调试

```text
launch-miaomiao-desktop.cmd
```

此方式不启动也不跟随 Codex，便于检查动画、拖动和鼠标交互。

## 关闭

- 右键妙妙即可关闭；
- 跟随模式下关闭 Codex 也会自动结束妙妙；
- 再次运行启动器不会产生第二个妙妙窗口。

## 调整位置与速度

编辑根目录 `miaomiao.config.json`：

```json
{
  "globalDurationScale": 1.0,
  "windowScale": 1.0,
  "idlePauseRangeMs": [3000, 6000],
  "hoverDwellMs": 500,
  "triggerCooldownMs": 2000,
  "codexWindow": {
    "placement": "outside-right-bottom",
    "offsetX": 16,
    "offsetY": -16
  }
}
```

`globalDurationScale` 大于 `1.0` 会整体放慢，小于 `1.0` 会整体加快。`offsetX`、`offsetY` 调整相对 Codex 右下角的位置；屏幕右侧空间不足时运行时自动回退到 Codex 窗口内部右下角，并保留边距。

## 旧版文件

Codex 原生宠物包、安装脚本及 WSL 兼容启动器位于 `legacy/codex-native/`。它们不再是推荐入口，也不参与当前 Windows 透明桌宠运行。
