# 动作与状态映射

当前唯一行为来源是 `pet/miaomiao/behavior.json + actions/`。Windows 透明桌宠运行时按 `miaomiao.config.json` 合并用户可调参数，不再把 Codex 原生状态行当作主要动画协议。

## 事件映射

| 事件 | 行为 |
| --- | --- |
| 单击 / 悬停 500ms | 按 `weights` 在 `roll`、`knead` 中随机，各 50% |
| 动作播放期间再次触发 | 忽略，不打断当前动作 |
| 明显水平向右拖动 | `running-right` |
| 明显水平向左拖动 | `running-left` |
| 主要垂直拖动 | 只移动窗口，不播放跑动 |
| 普通待机 | 先安静 3–6 秒，再按权重选择微动作 |
| 特殊待机检查 | 每 30–60 秒检查，30% 概率播放 `wash-face` |
| 右键 | 关闭桌宠 |

特殊洗脸的理论平均间隔为 `45 秒 / 0.30 ≈ 150 秒`，即约 2.5 分钟，而不是每次到点强制播放。

## 播放锁与速度

- `ignoreWhilePlaying: true` 保证 5–6 秒长动作不会被 hover 或点击打断；
- `globalDurationScale` 统一乘到所有逐帧时长和待机间隔；
- `1.0` 是默认速度，大于 `1.0` 更慢，小于 `1.0` 更快；
- 所有帧都是独立姿势或原始干净关键帧，不使用透明混合插帧。

## Windows 生命周期

统一启动器把 Codex 主窗口句柄和进程 ID 交给桌宠运行时。运行时每 100ms：

- 读取 Codex 窗口矩形并重算妙妙位置；
- 检测最小化状态并隐藏妙妙；
- 检测恢复并重新显示；
- 检测窗口句柄失效或进程退出并关闭妙妙。

命名互斥锁 `Local\MiaomiaoDesktopPet` 防止重复桌宠进程。
