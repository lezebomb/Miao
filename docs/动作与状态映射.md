# 动作与状态映射

妙妙保留两层兼容实现：

1. `pet/miaomiao/pet.json` 与 `spritesheet.webp`：标准 Codex v2 宠物包。
2. `pet/miaomiao/behavior.json` 与 `actions/`：项目自带的 Windows 交互桌宠扩展。

## Codex v2 固定映射

当前 Codex 客户端固定读取 `8×11` 图集：

| 图集行 | Codex 状态 | 客户端帧数 |
| --- | --- | ---: |
| 0 | `idle` | 6（另含 neutral） |
| 1 | `running-right` | 8 |
| 2 | `running-left` | 8 |
| 3 | `waving` | 4 |
| 4 | `jumping`（客户端 hover 临时状态） | 5 |
| 5 | `failed` | 8 |
| 6 | `waiting` | 6 |
| 7 | `running` | 6 |
| 8 | `review` | 6 |
| 9–10 | 16 个视线方向 | 16 |

本轮已把新 idle 的前 6 个姿势和新左右跑的前 8 个姿势写回标准图集。其余标准状态和视线方向保持现有素材。

`pet.json` 不读取自定义事件、概率权重或 idle 动作池，所以标准 Codex 浮窗无法直接实现 50/50 的抚摸随机分支。

## 项目交互桌宠映射

运行 `launch-miaomiao-desktop.cmd` 时，行为层读取 `behavior.json`：

| 事件 | 动作 |
| --- | --- |
| 鼠标进入妙妙 / 单击抚摸 | `roll` 与 `knead` 各 50% |
| 向右拖动 | `running-right` |
| 向左拖动 | `running-left` |
| 普通待机 | `idle` |
| 随机待机分支 | `wash-face`，冷却时间随机 35–65 秒 |
| 右键 | 关闭 |

动作有效帧数：

- `idle`：10
- `running-right`：10
- `running-left`：10
- `roll`：16
- `knead`：14
- `wash-face`：14

这些帧全部是独立完整姿势。构建脚本没有整图 alpha 混合、crossfade 或 tween。

## 重影和轮廓验证

`previews/actions-v2/validation.json` 包含：

- 大面积内部半透明像素检测
- 轮廓面积异常膨胀检测
- 不透明连通域和轮廓密度的双轮廓启发式检测
- 每帧前景面积、轮廓面积、质心和组件数据
- 明确的人工视觉结论；脚本默认是 `pending_manual_review`，不会自动写 `pass`

黑白背景动画和接触表位于：

- `previews/actions-v2/black/`
- `previews/actions-v2/white/`
- `previews/actions-v2/contact-sheet-black.jpg`
- `previews/actions-v2/contact-sheet-white.jpg`
