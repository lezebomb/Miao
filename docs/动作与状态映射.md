# 动作与状态映射

妙妙保留两套兼容层：

1. `pet/miaomiao/pet.json` + `spritesheet.webp` 是标准 Codex v2 宠物包。
2. `pet/miaomiao/behavior.json` + `actions/` 是项目自带的 Windows 交互桌宠扩展。

## Codex v2 固定映射

当前 Codex 26.715 的宠物渲染器固定读取 `8×11` 图集，标准动作帧数也由客户端写死：

| 图集行 | Codex 状态 | 帧数 |
| --- | --- | ---: |
| 0 | `idle` | 6 |
| 1 | `running-right` | 8 |
| 2 | `running-left` | 8 |
| 3 | `waving` | 4 |
| 4 | `jumping`（客户端 hover 临时状态） | 5 |
| 5 | `failed` | 8 |
| 6 | `waiting` | 6 |
| 7 | `running` | 6 |
| 8 | `review` | 6 |
| 9–10 | 16 个视线方向 | 16 |

`pet.json` 只识别宠物身份、描述、图集路径和图集版本；它不读取自定义事件映射、权重或随机动作池。因此标准 Codex 浮窗仍遵守客户端固定状态协议。

## 交互桌宠扩展映射

运行 `launch-miaomiao-desktop.cmd` 时，项目自己的行为层读取 `behavior.json`：

| 事件 | 动作 |
| --- | --- |
| 鼠标进入妙妙 / 单击抚摸 | `roll` 与 `knead` 各 50% |
| 向右拖动 | `running-right` |
| 向左拖动 | `running-left` |
| 普通待机 | `idle` |
| 随机待机分支 | `wash-face`，每次间隔随机为 35–65 秒 |
| 右键 | 关闭交互桌宠 |

动作帧数：

- `idle`：12 帧
- `running-right`：16 帧
- `running-left`：16 帧
- `roll`：16 帧
- `knead`：16 帧
- `wash-face`：16 帧

所有扩展帧均从已通过 QA 的妙妙 v2 图集关键帧构建，保持 `192×208`、透明背景和原有身份比例。生成过程使用重心配准、预乘 Alpha 和动作级过渡上限；跑动与打滚使用更低过渡权重，避免脸、腿和尾巴被插值拉坏。
