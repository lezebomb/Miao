# 妙妙角色身份规范

本文件是所有桌宠帧的外观“角色圣经”。照片与视频决定妙妙的身份，网络素材不得参与外观设计。

## 身份锚点

- 成年金渐层短毛猫，体型紧凑、正常、略圆润；站立比例正常，躺下时腹部显得更圆。
- 圆脸，短口鼻，粉色鼻头；下巴与嘴边为奶油白，表情安静、软萌、略带无辜感。
- 眼睛大而圆，虹膜为绿色；耳朵直立且偏尖，不做折耳或圆耳。
- 毛色为暖金底色叠加黑色毛尖，头顶和背部较深，胸口、下巴与腹部较浅。
- 四肢仅保留轻而细的层次，不画粗重黑色虎斑；四爪肉垫均为黑色。
- 尾巴为正常长度、较蓬松，有清楚但不过度的深浅环纹，尾尖必须为黑色。

## 比例与风格

- 风格比例：约 85% 真实形象，15% 为桌宠小尺寸阅读所需的简化。
- 单格目标为 `192×208`，正常状态尽量占单格高度的约 72%–82%，保留安全边距。
- 半写实、柔和、无粗黑描边；不是照片抠图拼贴，也不是 Q 版或贴纸风。
- 动作之间保持头部大小、身体长度、腿长、尾巴粗细和毛色分区稳定。
- 背景使用纯色抠像后转透明；不使用场景、地板、投影、光晕或漂浮特效。
- 完全静音，不包含声音文件。

## 禁止漂移

- 不得变成银渐层、橘猫、美短脸、尖脸或长条瘦猫。
- 不得出现夸张短腿、球形肥胖、超短尾、断尾、双尾、多腿、错位眼睛或肢体穿插。
- 不得丢失绿色圆眼、粉鼻、浅色下巴胸腹、环纹黑尾尖这些高优先级特征。
