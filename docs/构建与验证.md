# 构建与验证记录

## 动作构建

使用工作区捆绑 Python：

```powershell
& "<bundled-python>" scripts/build_action_assets.py --visual-verdict pending_manual_review
```

脚本从旧图集的干净关键帧、`pose-sources/roll`、`pose-sources/knead` 和 `pose-sources/wash-face` 重建唯一运行时动作包。旧图集只作为构建输入，位于 `legacy/codex-native/pet/miaomiao/spritesheet.webp`，不是运行依赖。

视觉检查黑白背景正常速度与 0.5 倍速 GIF 后，再运行：

```powershell
& "<bundled-python>" scripts/build_action_assets.py --visual-verdict pass
```

## 自动检查

`previews/actions-v3/validation.json` 记录：

- 每个动作的帧数、单周期与总时长；
- 半透明内部区域比例；
- 轮廓面积变化；
- 显著断开轮廓数量；
- 是否禁止 crossfade 与透明叠加；
- 人工视觉复核状态。

`launch-miaomiao-with-codex.ps1 -CheckOnly` 额外检查：

- Codex AppX 包和原生可执行文件；
- 配置与全部动作帧；
- 统一速度倍率；
- 移动/缩放跟随、最小化隐藏、恢复显示、关闭退出策略；
- 未使用 WSL 环境变量。

`scripts/test_desktop_lifecycle.ps1` 会创建一个短暂的临时宿主窗口，实际验证：

- 宿主移动后妙妙按相同位移跟随；
- 宿主最小化后妙妙隐藏；
- 宿主恢复后妙妙显示；
- 宿主窗口关闭后妙妙进程退出。

## 视觉检查清单

- 黑底与白底均无半透明双轮廓或重影；
- 没有多腿、多尾巴、双头或五官漂移；
- 打滚按“降低身体→肩先着地→侧躺→露腹→翻回→停留→起身”播放；
- 踩奶可读为左右前爪交替按压，肩膀轻微交替、头和后半身稳定，并有独立回待机段；
- 洗脸包含两次舔爪和两次贴脸下擦，爪子不穿脸；
- 所有长动作结束都回到安静姿势，没有透明混合过渡；
- 跑动保持原有 8 个独立关键帧，只放慢到 0.84 秒/周期。

Codex 主窗口的真实移动、最小化、恢复和关闭仍应在目标机器上做一次人工冒烟观察；自动检查验证的是句柄跟踪、状态分支和配置完整性，不会擅自最小化或关闭用户正在使用的 Codex。
