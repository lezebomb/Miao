# 构建与验证记录

## 实际 Codex 契约

- 图集：`1536×2288`
- 网格：`8` 列 × `11` 行
- 单格：`192×208`
- 标准动画行：`9`
- 视线方向：`16`，按 22.5° 顺时针排列
- 配置：`spriteVersionNumber: 2`
- 音频：无

## 生成与处理

1. 从 18 张照片锁定身份特征。
2. 从 4 段本地视频抽取 48 个关键帧和 4 张动作接触表。
3. 生成统一半写实母版。
4. 逐行生成 9 个标准状态；左移动最终采用独立生成，未使用会造成裁切的镜像版本。
5. 生成并修复四向锚点，再合成 16 个视线方向。
6. 确定性裁切、统一单格尺寸、组装 `8×11` 图集。
7. 对最终图集进行一次边缘去洋红污染和透明 RGB 清理。

## 通过的检查

- `qa/review.json`：所有标准行帧数正确，无结构错误或警告。
- `final/validation-extended.json`：`ok: true`，尺寸、行列、使用格与透明格均符合 v2。
- `qa/chroma-despill-extended.json`：`ok: true`，alpha 保持，透明像素无隐藏 RGB。
- `qa/cardinal-anchors.json`：四个方向锚点均通过边缘和语义检查。
- `qa/direction-blind-validation.json`：三份隔离盲测对 14 组方向对比均以 `3/3` 一致票通过。
- `qa/direction-semantics.json`：16 个方向全部为 `pass`。
- `qa/final-visual-qa.json`：独立最终视觉复核为 `pass`。
- `previews/theme-light.png` 与 `theme-dark.png`：浅色、深色 Codex 类背景下均可辨识。

## 已知设计取舍

- 小跑使用轻快短步的小跑/快走折中，优先保证 8 帧稳定和解剖自然。
- 洗脸压缩为 `review` 中的一次短擦脸；完整长洗脸不单独触发。
- 侧躺和轻露肚合并为 `failed` 的撒娇式短循环；不做多圈翻滚。
- Codex 固定状态没有独立的“趴下恢复”和“伸懒腰”触发位，因此未向配置写入无效字段。
