# 妙妙的视线方向机制

最佳自然动作是“眼睛先行，头颈轻微跟随，耳朵与胡须延迟半拍”，身体下半部保持稳定坐姿。妙妙不是刚性物体，不能旋转整只猫来假装看向某处。

## 稳定锚点

- 采用与 `waiting`/`review` 相近的紧凑坐姿。
- 两只前爪、臀部、尾巴根部和脚底基线固定；每格身体高度、头部大小和胸口位置一致。
- 蓬松环纹尾巴贴近身体，黑色尾尖始终连续，不在相邻方向突然换边。
- 不新增道具、阴影、动作线或漂浮特效。

## 参与动作的部位

- 大而圆的眼球在眼眶内整体转动，绿色虹膜、黑色瞳孔、眼白、眼睑和高光作为一个物理整体变化，不能只把瞳孔贴到固定眼白上。
- 眼睛领先方向；短口鼻、鼻尖和头部随后做小幅俯仰或左右转动。
- 上胸与肩部只做轻微跟随，避免脸或身体拉伸变形。
- 耳朵保持直立偏尖；转向侧的耳朵略外展，另一侧略后收。胡须随面部方向轻微变化。

## 四个方向姿态族

- `000 up`：鼻尖与双眼明确抬向画面上方，下巴稍抬，胸部与前爪不移动；两耳仍完整可见。
- `090 screen-right`：鼻尖和绿色虹膜位于头部中心右侧，左侧脸颊稍多可见，右侧脸颊略被口鼻遮挡；头部小幅向画面右侧转。
- `180 down`：眼睛和鼻尖明确向下，眼睑稍收、头部低俯，下巴靠近浅色胸口；不能读成闭眼或中性正脸。
- `270 screen-left`：鼻尖和绿色虹膜位于头部中心左侧，右侧脸颊稍多可见，左侧脸颊略被口鼻遮挡；与 `090` 明确相反。

## 连续性预算

每个 22.5° 步进只允许眼球、眼睑、头部角度、耳朵和上胸发生近似等量变化。相邻格不得出现身体缩放、基线跳动、尾巴换边、脸型变化或突然翻面。`157.5→180` 与 `337.5→000` 也必须是一格的自然过渡。
